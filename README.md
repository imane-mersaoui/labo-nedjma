# Labo Nedjma — Page d'accueil

Maquette de la nouvelle page d'accueil du site **Labo Nedjma**, laboratoires cosmétiques algériens.

Site statique en HTML, CSS et JavaScript, sans dépendance ni étape de build.

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension *Live Server* de VS Code.

## Structure

```
index.html     page d'accueil
styles.css     styles
script.js      slider, menus, animations
assets/        images et logos
```

> Seule la page d'accueil est publiée ici : les liens vers les autres pages (Le Groupe, Produits, Contact…) ne fonctionnent pas encore dans ce dépôt.
